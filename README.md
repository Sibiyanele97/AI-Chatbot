# AI Chatbot 🤖

An intelligent AI-powered chatbot designed to simulate human conversation and provide quick, interactive responses. This project demonstrates the use of modern web technologies and artificial intelligence concepts to create a responsive and user-friendly chat experience.

---

## 🚀 Features
- Real-time chat interface
- AI-generated responses
- Clean and modern UI
- Responsive design for mobile and desktop
- Fast and interactive communication
- Simple and user-friendly experience

---

## 🛠️ Technologies Used
- HTML
- CSS
- JavaScript
- AI API Integration

## ⚙️ Installation

1. Clone the repository

```bash
git clone https://github.com/Sibiyanele97/AI-Chatbot.git
```

2. Open the project folder

```bash
cd AI-Chatbot
```

3. Run the project by opening `index.html` in your browser
